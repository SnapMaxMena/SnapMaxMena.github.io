Unstructured data & file URL types
SnowPro Core — quick-review card
3 URL types — the whole exam in one section
🔒 Scoped URL
Expiry: 24 hrs (results cache period)
Auth: Only the user who generated it
Function: BUILD_SCOPED_FILE_URL()
Sharing: ✓ Works in secure views shared via Data Sharing
Best for: Scoped access to specific roles, custom apps, Snowsight analysis, sharing with data consumers
📁 File URL
Expiry: Permanent (never expires)
Auth: Role must have USAGE (ext) or READ (int) on stage
Function: BUILD_STAGE_FILE_URL() or query directory table
Sharing: ✗ Cannot be used in secure views for data sharing
Best for: Custom apps needing permanent persistent links + authorization control
🌐 Pre-signed URL
Expiry: Configurable (set via expiration_time)
Auth: Anyone with the URL — no Snowflake auth needed
Function: GET_PRESIGNED_URL()
Sharing: ✓ Works in secure views shared via Data Sharing
Best for: BI tools, browsers, reporting — no login needed. Open access.

Server-side encryption — internal stage exam trap
Default (client-side encryption)
Files are unreadable via pre-signed, file, or scoped URLs. External tools cannot access the files.
Server-side encryption (SNOWFLAKE_SSE)
Files are readable via URLs. Required for unstructured data access on internal stages.
Set at stage creation — cannot be changed later.
⚠ If you need Tri-Secret Secure: use SNOWFLAKE_FULL — NOT SNOWFLAKE_SSE. SSE does not support Tri-Secret Secure.

Other key concepts
Directory tables
Catalog of staged files in cloud storage. Query to retrieve file URLs. Must be enabled at stage creation (DIRECTORY = (ENABLE = true)).
FILE data type
Represents a file in a stage. Convert using TO_FILE() or TRY_TO_FILE(). Accepted by built-in functions in place of stage + path.
