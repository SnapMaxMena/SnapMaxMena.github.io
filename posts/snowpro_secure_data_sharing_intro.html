Secure Data Sharing — intro
SnowPro Core — quick-review card
The single most-tested concept
⚡ NO data is copied or transferred between accounts
Sharing uses Snowflake's services layer + metadata store only.
Shared data takes up zero storage in the consumer account → no storage charges to the consumer.
Consumer is only charged for the virtual warehouse compute used to query the data.

⚠ All shared objects are read-only — consumers cannot modify, insert, update, or delete data.
4 ways to share data in Snowflake
📋 Direct Share
Share specific DB objects directly to another account in the same region. Point-to-point.
🛒 Listing
Offer share + metadata as a data product to one or more accounts (including Marketplace). Can convert a Direct Share to a Listing.
🔗 Data Exchange
Set up and manage a private group of accounts. Share within that curated network. Usage metrics available.
🧹 Clean Room
Share data with query restrictions — control exactly which queries consumers can run against your data.
Provider vs consumer — key rules
🏭 Provider
• Creates the share
• Grants objects via DB role OR directly
• Adds consumer accounts to share
• Can create unlimited shares
• Can add unlimited accounts to a share
• Can revoke access anytime
• Can share from multiple DBs (same account only)
🏢 Consumer
• Creates read-only DB from share
• 1 DB per share (cannot consume same share twice)
• Can consume unlimited shares
• Queries data like any local DB
• Pays only for compute (WH)
• Zero storage cost for shared data
A full Snowflake account can be BOTH a provider and a consumer simultaneously.
