Schema detection tools
INFER_SCHEMA — auto-detects column names, types, order from staged files (Parquet, Avro, ORC, JSON, CSV).
GENERATE_COLUMN_DESCRIPTION — generates column list from INFER_SCHEMA output.
CREATE TABLE … USING TEMPLATE — creates table directly from INFER_SCHEMA output. Then use COPY … MATCH_BY_COLUMN_NAME to load.
