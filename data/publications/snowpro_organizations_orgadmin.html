Two org admin roles — compare
⚠️ ORGADMIN (being phased out)
Lives in ORGADMIN-enabled regular accounts (up to 8).
Granted to users by ACCOUNTADMIN using GRANT ROLE.
Not in the standard role hierarchy — sits outside it.

Still works but being deprecated for multi-account orgs. Snowflake notifies 3 months before removal.
✅ GLOBALORGADMIN (preferred)
Lives exclusively in the Organization account (special account type).
Recommended for multi-account organizations going forward.

Sign in to the org account → USE ROLE GLOBALORGADMIN;
⚠ ORGADMIN is NOT part of the standard role hierarchy (ACCOUNTADMIN → SYSADMIN → USERADMIN chain). It is a separate, standalone system role.
What ORGADMIN can & cannot do
Create accounts in the organization
View/list all accounts in the org
View list of regions for the org
View usage info for all accounts (ORGANIZATION_USAGE schema)
Enable database replication for accounts
Enable ORGADMIN in other accounts (IS_ORG_ADMIN = TRUE)
Access account data after creating an account
Enable ORGADMIN on a reader account
Disable ORGADMIN on the last enabled account (need Support)
Change org name (need Snowflake Support)
SQL quick reference
Enable ORGADMIN in another account
USE ROLE ORGADMIN;
ALTER ACCOUNT my_account1 SET IS_ORG_ADMIN = TRUE;
Disable ORGADMIN in an account (from a DIFFERENT ORGADMIN account)
USE ROLE ORGADMIN;
ALTER ACCOUNT account_123 SET IS_ORG_ADMIN = FALSE;
Grant ORGADMIN role to a user (ACCOUNTADMIN only)
USE ROLE ACCOUNTADMIN;
GRANT ROLE ORGADMIN TO USER <username>;
View all org accounts
SHOW ACCOUNTS;
Get current org name (any role)
SELECT CURRENT_ORGANIZATION_NAME();
ALTER ACCOUNT accepts account name format only — NOT account locator format.
Why organizations exist — 5 benefits
🔍 Visibility
Central view of all accounts. View usage across all accounts via ORGANIZATION_USAGE views.
⚡ Self-service
Create new accounts without contacting Snowflake Support.
🔄 Replication
Data availability + disaster recovery via replication and failover across accounts.
🌍 Data sharing
Seamless sharing with consumers across cloud regions.
