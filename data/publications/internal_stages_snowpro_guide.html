Named stage — create syntax
CREATE STAGE my_int_stage ENCRYPTION = (TYPE = 'SNOWFLAKE_SSE');
Encryption type cannot be changed after creation. Use SNOWFLAKE_SSE for server-side (enables data access); default is client-side (files unreadable when downloaded).
Table stage gotcha: no grantable privileges of its own — access = OWNERSHIP on the table. Cannot transform data on load.
User stage gotcha: if current user lacks INSERT on the target table, this stage is not appropriate.
Which stage should I use?
Always recommended: Named stage for any regular, multi-user, or multi-table data load. It is the most flexible and the only type with grantable privileges.
