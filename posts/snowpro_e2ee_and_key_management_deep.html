Customer-managed keys (CMK) + Tri-Secret Secure Business Critical+
CMK lives in cloud KMS: AWS KMS · Azure Key Vault · GCP Cloud KMS
Composite master key = Snowflake AMK + CMK → Tri-Secret Secure
CMK rotation in cloud → Snowflake picks up new version at next AMK rotation (~30 days, not immediately)
CMK unavailable > 10 minutes → all Snowflake data ops halt completely
Never delete old CMK versions — Snowflake still needs them to decrypt older files. Deletion = permanent data loss.
