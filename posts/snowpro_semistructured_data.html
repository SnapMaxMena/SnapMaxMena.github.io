The 3 semi-structured data types — know all 3
🧰 VARIANT
Universal container. Holds any data type — including ARRAY and OBJECT.

Max single value: ~16 MB compressed.

The go-to type for storing entire JSON/Avro/Parquet documents.
📦 OBJECT
Key-value pairs.
= JSON object / dictionary / map / hash.

Keys = strings.
Values = VARIANT.

⚠ NOT "object" as in OOP.
📋 ARRAY
Ordered list of values.
Each cell = VARIANT.

Can hold any type, including nested OBJECTs or ARRAYs.
Key nesting rule: VARIANT wraps everything. ARRAY and OBJECT hold VARIANTs. VARIANTs hold ARRAYs/OBJECTs/scalars. They can be combined to infinite depth.
How the hierarchy works — visual
VARIANT can hold:
  ├── OBJECT { key: VARIANT, key: VARIANT }
  │    └── values are VARIANT → can be ARRAY, OBJECT, or scalar
  ├── ARRAY [ VARIANT, VARIANT ]
  │    └── cells are VARIANT → can be ARRAY, OBJECT, or scalar
  └── scalar (STRING, NUMBER, DATE…)
Snowflake automatically builds the hierarchy when loading JSON/Avro/Parquet/ORC — no manual mapping required.
Supported input formats
JSON Avro ORC Parquet XML
JSON / Avro / ORC / Parquet → Snowflake auto-parses into VARIANT/ARRAY/OBJECT. XML → use XMLGET() function for querying.
2 ways to store semi-structured data
Path A — Single VARIANT column
Store the entire document as-is in one VARIANT column. Simplest approach.

CREATE TABLE t (col VARIANT);
COPY INTO t FILE FORMAT=(TYPE='JSON');

Or insert with:
INSERT INTO t SELECT PARSE_JSON('{...}');
Path B — Split across multiple columns
Extract fields into separate typed columns during/after load.

Options:
• Manual: extract + transform with SQL
• Auto: Snowflake detects column definitions from staged files → creates table automatically

Some columns can still be VARIANT; others become VARCHAR, NUMBER, etc.
Use multiple columns when individual values exceed ~128 MB compressed storage per VARIANT value.
Key SQL functions
Parse JSON string → VARIANT
PARSE_JSON('{"a":1}')
Access OBJECT key (colon notation)
col:key or col['key']
Access ARRAY element (bracket)
col[0] → first element
Traverse nested hierarchy
col:level1:level2 (dot-like path)
Query XML tags
XMLGET(col, 'tag')
Cast VARIANT value
col:key::STRING
col:key::NUMBER
