Appearance modes — username → Appearance
☀️ Light
Dark text on light background. Normal conditions.
🖥 System
Matches OS setting (e.g. macOS appearance setting).
🌙 Dark
Light text on dark background. Low-light conditions.
Appearance setting is persistent at the user level — survives logout/login. Not set by default on first login → prompted to choose.
Programmatic access token
Generated in Settings → Authentication. Used to authenticate to Snowflake REST APIs, SQL API, Catalog SDK, and Snowpark Container Services.
Alternative to username/password for programmatic access — does not require MFA prompt.
