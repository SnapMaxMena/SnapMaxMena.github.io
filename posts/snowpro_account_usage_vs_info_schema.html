Two schemas inside the SNOWFLAKE database
ACCOUNT_USAGE
Object metadata + historical usage for your account. Includes dropped objects. 1-year retention.
READER_ACCOUNT_USAGE
Subset of AU views for all reader accounts you created (Secure Data Sharing provider). Adds READER_ACCOUNT_NAME column. Empty if no reader accounts exist.

Dropped objects — how ACCOUNT_USAGE handles them
Views include a DELETED column with the drop timestamp.
ID columns distinguish objects re-created with the same name (different internal IDs).
If TABLE_NAME (or any object name column) = NULL → object was dropped AND its parent DB/Schema names are also NULL.
Some views still show the name even after drop — use the DELETED timestamp or ID to confirm.
Best practices — exam-relevant rules
Never use SELECT * on ACCOUNT_USAGE views — Snowflake may change columns. Always select specific columns.
To reconcile with ORGANIZATION_USAGE views (e.g. billing): run ALTER SESSION SET TIMEZONE = UTC first.
Use SNOWFLAKE database roles (not IMPORTED PRIVILEGES) for least-privilege access to ACCOUNT_USAGE.
READER_ACCOUNT_USAGE views are empty unless reader accounts exist for your account.
